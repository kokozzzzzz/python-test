- Python 3.13.14

## 安装步骤
    1.克隆项目
        ```bash
        git clone https://github.com/yourname/project.git
        cd project

    2.创建虚拟环境
        bash
        python -m venv .venv

    3.激活虚拟环境

        Windows:

        bash
        .venv\Scripts\activate
        macOS / Linux:

        bash
        source .venv/bin/activate

    4.安装依赖

        bash
        pip install -r requirements.txt
